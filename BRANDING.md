# Modstoke branding

Modstoke is a family of independent modding tools published by OpenACAI, a nonprofit. Use the credit **by OpenACAI** with the product name.

| Product | Name |
| --- | --- |
| Desktop manager | Modstoke Manager |
| Game loader | Modstoke Loader |
| Admin mod | Modstoke Admin |
| Development kit | Modstoke SDK |
| Website and mod catalog | Modstoke |

The intended website is **modstoke.com**. Registration, HTTPS and service deployment are separate work; this repository does not establish that the site is ready. Existing update and download addresses remain in use.

The manager supports **Sons of the Forest**. It is not affiliated with or endorsed by Endnight Games. Keep the game name in compatibility descriptions and retain upstream software notices.

## Product artwork

`public/modstoke-mark.svg` is the source for the manager's amber M and ember mark. Application and installer icons are generated from it with `tauri icon`. `docs/assets/modstoke-banner.svg` is the source for the Nexus page banner.

Display names do not determine installed identities. See [rename compatibility](docs/BRAND_COMPATIBILITY.md) before changing package names, paths or integration IDs.

## Publisher artwork

`public/openacai-mark.svg` preserves the symbol-only SVG recreation of the public OpenACAI Inc mark.

Reference sources:

- OpenACAI Inc BBB Business Profile: `https://www.bbb.org/us/mo/farmington/profile/non-profit-organizations/openacai-inc-0734-1000042204`
- OpenACAI website: `https://openacai.com/`

Only the OpenACAI symbol portion is used. The BBB seal and the OpenACAI Inc wordmark from the source image are not included in the manager assets.
